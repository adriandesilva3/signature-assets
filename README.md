# Signature assets

Images for the Title Hospitality email signatures, served by GitHub Pages so every mail
client fetches a real PNG.

## The address of any file here

Take the file's path in this repository and put it after
`https://adriandesilva3.github.io/signature-assets/`. For example
`republic-tavern/Campaign_Functions.png` is served at
`https://adriandesilva3.github.io/signature-assets/republic-tavern/Campaign_Functions.png`.

The address in your browser when you click a file on github.com is a web page, not the
image, and will not work in a signature. The signature builders convert it automatically if
you paste it, but the `github.io` form is the real one. Spaces in a name become `%20`, so
names without spaces are easier: `Mantra_Wave.png` rather than `Mantra Wave.png`.

## Sizes

Every file must be exactly the size its slot expects, because phone mail apps show a hosted
image at its own pixel size whatever the signature asks for. The builders' resize step
produces files at these sizes.

| Slot | Size |
|---|---|
| Republic Tavern logo | 114 x 47 |
| Republic Tavern campaign | 300 x 167 |
| Mantra brand panel | 207 x 115 |
| Mantra wave | 290 x 40 |

## Changing a campaign

Upload the new 300 x 167 PNG here (Add file, Upload files). Either give it a new name and
paste its address into the builder, or upload it over the existing file under the same name
so the address does not change and nobody re-pastes their signature.

The signature builders live in the wiki under `work/republic-tavern/brand/email-signature/`
and `work/mantra-epping/brand/signature/`.

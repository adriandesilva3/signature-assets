# Signature assets

Images for the Title Hospitality email signatures, served by GitHub Pages so every mail
client fetches a real PNG. Squarespace's image CDN converts to WebP for clients that do not
ask for PNG, and Outlook on a phone cannot show WebP, which is why these live here instead.

| Signature | File | Size |
|---|---|---|
| Republic Tavern | `republic-tavern/republic-tavern.png` | 114 x 47 |
| Republic Tavern | `republic-tavern/campaign.png` | 300 x 167 |
| Mantra Melbourne Epping | `mantra-epping/mantra-lockup.png` | 207 x 115 |
| Mantra Melbourne Epping | `mantra-epping/mantra-wave.png` | 290 x 40 |

Keep every file at exactly the size listed. Phone mail apps show a hosted image at its own
pixel size, whatever the signature asks for.

To change the campaign: replace `republic-tavern/campaign.png` with a new 300 x 167 PNG
under the same name. The address does not change, so nobody re-pastes their signature.
The signature builders that produce these files live in the wiki under
`work/republic-tavern/brand/email-signature/` and `work/mantra-epping/brand/signature/`.
